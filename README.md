# 🧭 Task Compass

**Learn how work flows through real organizations.**

Task Compass is a startup management simulation, not a quiz. It teaches
ownership, delegation, collaboration and how work moves through a company.

👉 **Play it:** https://rankendra23.github.io/task-compass/

## How it works

| Stage | Name | What you do |
|-------|------|-------------|
| 1 | Who Owns This? | Drag the right role onto a realistic startup problem |
| 2 | Task Routing | Build the workflow in the right order |
| 3 | Collaboration Challenge | Assemble up to 4 roles for bigger situations |

Each answer reveals the reasoning: who usually owns the work, who assists,
and how the team might communicate. There is no "correct/wrong" buzzer.

At the end you get an understanding map across **Ownership, Delegation,
Collaboration and Workflow Thinking**, plus a short reflection.

## Features

- Drag-and-drop role cards (tap to place on mobile)
- Animated task flow, snap effects and a completion celebration
- Dark glassmorphism design
- One self-contained HTML file: no libraries, no APIs, works offline

## Run locally

Download `index.html` and open it in any modern browser.
